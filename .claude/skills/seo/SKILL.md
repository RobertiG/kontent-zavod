# SEO карточки

Регламент — `processes/seo.md`. Цель — карточка находится по запросам, которые покупают, и не собирает мусорный трафик.

## Запуск

Прочитай `processes/obshchie-pravila.md`. Обычно навык запускает `/kontent`: находит товар в CRM, скачивает нужное в `_work/<ID>/вход/`, а потом переносит `_work/<ID>/готово/` в папку товара. Вызвали напрямую по названию товара — сначала шаги 1–4 `/kontent`.

## Что нужно на входе

- Паспорт: `паспорт.md` и `данные_<артикул>.json` из свежей «Исходники / Паспорт и фото — …» — единственный источник фактов.
- Аналитика не старше 30 дней: `аналитика.json` из «Исходники / Аналитика — …» — запросы с частотой, конкуренты, «не писать». Нет или старая — `/kontent` сначала запускает `analitika`.
- Категория товара на каждой площадке — из аналитики (категории ближайших конкурентов).

## Шаги

1. **Правила площадки на дату.** Открой официальную справку Ozon и WB по названию, описанию, характеристикам и хештегам Ozon: длина, число, формат, запрещённые слова и символы. Запиши в `seo.md` (раздел «Правила на дату») каждую цифру со ссылкой и датой. По памяти и по карточкам конкурентов лимиты не берём. Справка недоступна — пиши «лимит не подтверждён» и делай поле коротким.
2. **Поля категории.** Список характеристик категории: обязательные, необязательные и допустимые значения. Источник по порядку: кабинет или API площадки — только если доступ у сотрудника уже есть (ключи в чат не просим, у клиента студии не запрашиваем); иначе — поля 2–3 конкурентов той же категории (WB — `wb_card_content`, Ozon — вкладка «Характеристики» на странице товара). Откуда взят список — запиши; если по конкурентам — пометь «список может быть неполным, сверить в кабинете при загрузке».
3. **Ключевые запросы.** Возьми запросы из аналитики и добери у 3–5 конкурентов: `wb_sku` / `ozon_sku` с `report=keywords`. Оставь только про наш тип товара и наши подтверждённые свойства (нет Bluetooth в паспорте — нет «bluetooth» в тексте), без чужих брендов. Разложи: главные — в название, второстепенные — в описание, уточняющие — в характеристики и хештеги. Каждое слово — один раз и в своём поле.
4. **Тексты.** Отдельно для Ozon и WB:
   - **Название** — по правилам площадки из шага 1 (у Ozon и WB они разные); тип товара и главное отличие, без превосходных степеней.
   - **Описание** — простым языком, от пользы покупателя к подтверждению из паспорта; абзацы короткие; ключевые слова вписаны естественно, без перечня через запятую. Боли из аналитики закрываем фактами, не обещаниями.
   - **Характеристики** — по списку из шага 2, значения только из паспорта и из списка допустимых. Нет в паспорте — поле пустое и попадает в «Чего не хватает».
   - **Хештеги Ozon** — по формату и числу из шага 1, только релевантные запросы.
5. **Подсчёт и сверка.** Длину каждого поля посчитай программой (`len` в Python), сравни с лимитом. Каждое число и свойство в текстах найди в паспорте. Сверь со списком «не писать» из аналитики.
6. **Сохрани** `seo.md` и `seo.csv`. CSV собирай модулем `csv` (не вручную): кодировка UTF-8 с BOM и разделитель «;» — так Excel откроет русский текст без кракозябр.

## Что получаем

Папка `_work/<ID>/готово/Карточка товара/SEO — ГГГГ-ММ-ДД/`:

- `seo.md` — по каждой площадке: название, описание, характеристики (поле — значение — где в паспорте), хештеги Ozon, ключевые запросы (запрос — частота — в каком поле стоит), правила на дату со ссылками, «Чего не хватает в паспорте».
- `seo.csv` — столбцы `площадка;поле;значение;символов;лимит;ключевые_слова;источник_в_паспорте` — для переноса в кабинет.
- `Рабочие_материалы/` — все собранные запросы с частотой и периодом, список полей категории с источником, описания конкурентов (только для анализа).

## Проверка

- [ ] Все запросы — про наш товар; нет чужих брендов и свойств, которых у товара нет.
- [ ] Каждое ключевое слово стоит один раз и в нужном поле.
- [ ] Длина каждого поля не больше лимита на дату, у лимита есть ссылка.
- [ ] Характеристики заполнены по списку категории; значения совпадают с паспортом, пустые перечислены.
- [ ] Тексты без опечаток, без «лучший», «№ 1» и обещаний сверх паспорта.
- [ ] `seo.csv` открывается в Excel, русский текст читается, строк столько же, сколько полей в `seo.md`.

## Если не получилось

- **Нет списка полей категории** — заполняй по конкурентам и честно помечай неполноту.
- **MPStats не дал частоту** — запрос оставь только если он из выдачи конкурентов, пометь «частота не проверена».
- **В паспорте мало фактов** — не дописывай из карточек конкурентов: перечисли, что прислать (характеристики, инструкция), и сделай текст на том, что есть.
- **Площадка требует то, чего нет в паспорте** (обязательное поле) — оставь пустым, отметь «обязательное — нужны данные».
- На площадку ничего не загружаем: тексты переносит человек.
