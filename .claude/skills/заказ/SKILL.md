# /заказ — путь заказа

Регламент: `processes/zakaz.md`. Правила учёта — `CLAUDE.md`. Вход: $ARGUMENTS.

**Новый заказ («занеси заказ»)**
1. Клиент есть? `uv run crm/crm.py get Клиенты --where "Контакт=…"`. Нет — сначала `/клиент`.
2. Собери из переписки: товар, площадка, ссылка на карточку, состав (названия строго из листа «Прайс»: `uv run crm/crm.py get Прайс`), скидка, порядок оплаты (первые 10 заказов — постоплата, дальше 50 на 50, Kwork — через Kwork; скрипт скажет, если не так), дедлайн. Несколько товаров — каждый отдельным заказом-товаром: первый обычной командой, следующие с `--to <номер>`.
3. Покажи человеку, что запишешь, включая сумму «К оплате» (скрипт посчитает по прайсу и скидке), дождись «да». При «50 на 50» в ответе скрипта есть «предоплата за весь заказ …» — после последнего товара заказа это итоговая сумма предоплаты для клиента; назови её Кристине.
4. `uv run crm/crm.py add-order --client К-… --set "Канал=…" --set "Товар=…" --set "Площадка=…" --set "Состав=…" --set "Порядок оплаты=…" [--set "Скидка=первый заказ 10%" --set "Кейс=разрешил"] [--set "Дедлайн=дд.мм.гггг"]`
5. Файлы клиента: покажи список файлов, которые загрузишь, дождись «да», затем `uv run crm/crm.py upload --order 0012-1 --sub ТЗ <файлы>`. ТЗ: заполни `templates/tz.md` по переписке → `_work/0012-1/тз.md` → `upload --order 0012-1 --sub ТЗ --move _work/0012-1/тз.md`.
6. Переписку сохрани в папку клиента (как в `/клиент`, шаг 5).

**Смена этапа** — `uv run crm/crm.py set Заказы 0012-1 --set "Статус=…"`. Скрипт не пустит в неправильный этап и скажет, чего не хватает. «50 на 50» — в работу только после предоплаты 50% всего заказа (её проверяет скрипт по всем товарам заказа сразу).
- Клиент прислал правки → `Статус=правки` (круг прибавится сам; с третьего — платно: после согласия клиента `--set "Состав=<прежний состав>, Доп. круг правок"`, сумма пересчитается).
- Оплата пришла → `uv run crm/crm.py pay 0012-1 --sum <сумма> --method <Продамус / перевод на счёт ИП / Kwork / другое>`; пришла не сегодня — `--date дд.мм.гггг`. Один платёж за весь заказ — `pay 0012 --sum …`, скрипт разделит по товарам. «Оплачено» и «Статус оплаты» скрипт ставит сам — руками их не задавай.
- На согласование → файлы в `На согласование` (`upload … --sub "На согласование"`), затем `share 0012-1 preview` и ссылку — Кристине для отправки.
- Сдача → после полной оплаты: `share 0012-1 result`, `Статус=выполнен` (дата «Сдан» встанет сама), затем `uv run crm/crm.py clean`.

**Сводка** — `uv run crm/crm.py get Заказы --where "Статус!=выполнен"` и `uv run crm/crm.py check`: перескажи коротко — что в работе, у чего дедлайн, что ждёт оплаты, какие ошибки.

**Отчёт к созвону во вторник** — `uv run crm/crm.py report`: деньги за 7 дней (внешние и УК отдельно, комиссия Kwork и сколько дойдёт на счёт), новые и повторные заказы по источникам, сданное, места MVP с постоплатой, реклама по кодам (расход, обращения, оплаты, цена обращения), партнёры (заказы, повторные), пробные обложки. **В начале месяца** — `report --month мм.гггг`: выплаты партнёрам (15% от денег, пришедших от их клиентов; после выплаты — `add Выплаты …`) и стоимость единицы (расходы на нейросети из «Расходов» / готовые работы за месяц).

Клиенту ничего не отправляй сам: готовишь текст и ссылку, отправляет Кристина.
