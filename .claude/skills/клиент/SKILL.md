# /клиент — новый или существующий клиент

Вход: $ARGUMENTS — переписка, ник, телефон или имя.

1. Поиск дубля. `uv run crm/crm.py get Клиенты --where "Контакт=<ник или телефон>"`, затем по имени. Нашёлся — не создавай второго: покажи его и спроси, что обновить (`set Клиенты К-…`).
2. Поля из переписки: Имя, Канал связи (Telegram / MAX / Kwork / телефон / email / другое), Контакт, ID чата (если есть), Источник, Код источника — промокод партнёра или код размещения `R-…`: клиент с рекламы обычно присылает первое сообщение «…код R-0005». Источник и код не угадывай — спроси одним коротким сообщением всё, чего не хватает.
3. Покажи строку целиком и дождись «да».
4. `uv run crm/crm.py add Клиенты --set "Имя=…" --set "Канал связи=…" --set "Контакт=…" --set "Источник=…" [--set "Код источника=…"] [--set "ID чата=…"]`
5. Переписка: сохрани присланный текст в `_work/К-…/переписка дд.мм.гггг.md` и `uv run crm/crm.py upload --client К-… --move "_work/К-…/переписка дд.мм.гггг.md"` (копия на компьютере удалится после проверки). Если такой файл уже есть на Диске — добавь к имени время.
6. Ответ человеку: ID клиента, ссылка на папку, что дальше (обычно — `/заказ`).
