# /релиз

1. `git switch main && git pull --ff-only`. Есть незакоммиченные изменения или открытые запросы на слияние (`gh pr list`) — покажи их Роберту и спроси, ждать ли.
2. Последний тег: `git describe --tags --abbrev=0` (нет тегов — первый релиз v0.1). Следующий: v0.N+1; v1.0 — только по слову Роберта.
3. Что вошло: `git log <последний тег>..HEAD --oneline`. Составь запись по-русски: «Добавлено», «Изменено», «Исправлено» — простыми словами, без хэшей.
4. Покажи запись Роберту, после «да» — ветка `release/v0.N`, запись в начало `CHANGELOG.md`, коммит `документация(релиз): v0.N`, `gh pr create`, после слияния Робертом: `git switch main && git pull && git tag v0.N && git push origin v0.N && gh release create v0.N --notes-file <запись>`.
5. Если в учёте студии что-то не сходится (заказ без строк, оплата без статуса), назови это в ответе.
