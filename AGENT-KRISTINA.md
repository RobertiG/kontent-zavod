## Часть 1. Для Кристины

Что получится: Claude на вашем компьютере ведёт учёт — заводит клиентов и заказы в таблицу, создаёт папки заказов на Google Диске, загружает туда файлы, меняет статусы и напоминает правила (оплата, правки, скидки). Записывает он не от вашего имени, а через отдельного «робота» Google — так видно, что сделал агент, а что человек.

Нужно заранее:
1. Подписка Claude **Pro или Max** (в бесплатной нет Claude Code — без него агент не сможет записывать в таблицу).
2. Приложение Claude для компьютера (claude.com/download), вход в ваш аккаунт.
3. Аккаунт на GitHub (github.com). Роберт спросил логин в самом начале; если аккаунта ещё нет — заведите на github.com/signup (3 минуты) и сообщите логин Роберту. Приглашение в проект придёт письмом — нажмите «Accept invitation».
4. Ваш Google-аккаунт, который Роберт добавил на общий диск «Контент завод».
5. Файл-ключ `agent-key.json` от Роберта. Если у вас обоих Mac — через AirDrop; иначе — лично на флешке; если никак — файлом в личном чате Telegram, и откройте этот чат **на компьютере** (в Telegram на телефоне файл останется на телефоне). Сохраните файл в «Загрузки». Никому не пересылайте; как только агент скажет «ключ на месте» — удалите сообщение с ключом у себя и у Роберта.

Что придётся сделать руками (агент скажет, когда): нажать «Установить» в окне системы, ввести пароль компьютера, войти в GitHub в браузере и ввести короткий код, нажимать «Разрешить» на вопросы Claude. Займёт 20–40 минут.

Как начать: Claude → вкладка **Code** → **Local** → **Select folder** → создайте и выберите пустую папку (например «Документы/Настройка агента») → перетащите этот файл в окно → напишите: «Настрой себя по этому файлу».

После настройки каждый раз открывайте в Code папку **kontent-zavod** в вашей домашней папке и говорите обычными словами:

| Вы говорите | Агент делает |
|---|---|
| «Новый клиент, вот переписка: …» | ищет дубль, заводит клиента, сохраняет переписку |
| «Занеси заказ: точилка, карточка под ключ, срок 5 ноября» | заводит заказ, считает сумму по прайсу, создаёт папку |
| «Фото от клиента в Загрузках, положи в заказ 0012-1» | показывает список файлов и загружает их после вашего «да» |
| «Отправь 0012-1 на согласование» | ставит этап, даёт ссылку на превью — отправляете вы |
| «Клиент оплатил 6 600 по 0012 вчера, Продамус» | вносит платёж с датой, делит между товарами заказа, сам ставит «предоплата получена» или «оплачен» |
| «Новое размещение: @канал, 5 000, ERID …» | заводит размещение, даёт код R-… и готовую ссылку для поста |
| «Отчёт к созвону» | деньги за неделю, новые заказы, реклама по кодам, партнёры, пробные обложки |
| «Пришли правки по 0012-1» | ставит «правки», считает круги, предупредит о платном круге |
| «Что у нас в работе?» | сводка: этапы, дедлайны, кто не оплатил, ошибки в учёте |
| «Заплатила за Kling 2 400 ₽» | вносит расход; в начале месяца по расходам считается стоимость одной работы |

Таблицу можно править и руками: выбирайте значения из выпадающих списков, не меняйте первую строку и номера. Деньги руками не вписывайте — говорите агенту «клиент оплатил». После ручной правки скажите агенту «проверь учёт».

## Часть 2. Для агента: настройка

Правила настройки:
- Делай шаги по порядку. После каждого шага — проверка. Проверка не прошла — **остановись**, объясни Кристине простыми словами, что не так и кто поможет (обычно Роберт), и не переходи дальше.
- Говори с Кристиной по-русски, без технических слов. Прежде чем что-то устанавливать, скажи одной фразой, что и зачем.
- Никогда не открывай, не печатай и не копируй содержимое файла-ключа.
- Если в блоке «Данные проекта» остался `<ВПИСАТЬ>` — остановись: «Роберт не вписал данные проекта, попросите его прислать файл заново».
- Команды ниже для macOS; для Windows — вариант после «Windows:» (PowerShell).

**Шаг 0. Где ты работаешь.** Проверь, что можешь выполнять команды (например `echo ok`). Не можешь (это обычный чат Claude) — остановись и скажи: «Я открыт как обычный чат. Откройте приложение Claude → вкладка Code → Local → Select folder и повторите». Подписка без вкладки Code — нужна Pro или Max. Определи систему: `uname -s` (Darwin — Mac); иначе Windows.

**Шаг 1. Инструменты:** git (хранит версии правил), uv (запускает скрипт учёта), gh (вход в GitHub).
- git: `git --version`. Нет на Mac → `xcode-select --install`, Кристина нажимает «Установить», ждём окончания. Windows: `winget install --id Git.Git -e`, затем перезапустить приложение Claude.
- uv: `uv --version`. Нет → `curl -LsSf https://astral.sh/uv/install.sh | sh` (Windows: `winget install --id astral-sh.uv -e`). Если после установки «command not found» — используй `~/.local/bin/uv` или перезапусти сессию.
- gh: `gh --version`. Нет → `brew install gh`, если есть brew; иначе скачай с https://github.com/cli/cli/releases/latest архив для macOS под архитектуру (`uname -m`: arm64 или x86_64), распакуй и положи `bin/gh` в `~/.local/bin/`. Windows: `winget install --id GitHub.cli -e`.
- Проверка: `git --version && uv --version && gh --version` — три версии.

**Шаг 2. GitHub.** `gh auth status`. Не вошли → `gh auth login --hostname github.com --git-protocol https --web`: покажи Кристине код из 8 знаков, она вводит его на открывшейся странице и нажимает «Authorize». Затем `gh auth setup-git`.
- Проверка: `gh repo view <репозиторий из «Данных проекта»> --json name`. Ошибка «Could not resolve» или 404 — приглашение не принято: попроси Кристину открыть письмо от GitHub или github.com/notifications и нажать «Accept»; если письма нет — сообщить логин Роберту.

**Шаг 3. Репозиторий.** `cd ~ && gh repo clone <репозиторий>` (Windows: `cd $HOME; gh repo clone <репозиторий>`). Только в домашнюю папку — не на «Рабочий стол», не в «Документы», OneDrive, iCloud, Яндекс Диск: они синхронизируются с облаком, git там ломается, а файлы клиентов копируются в личное облако.
- Проверка: файл `~/kontent-zavod/CLAUDE.md` существует.

**Шаг 4. Ключ робота-агента.** Найди файл, не открывая его: `find ~/Downloads ~/Desktop -maxdepth 3 -name 'agent-*.json' 2>/dev/null` (Windows: `Get-ChildItem "$HOME\Downloads","$HOME\Desktop" -Recurse -Depth 2 -Filter 'agent-*.json'`). Не нашёл — спроси Кристину, куда она его сохранила; если файл пришёл только на телефон — попроси открыть тот же чат Telegram на компьютере и скачать файл в «Загрузки». Перенеси, не открывая, под точным именем `agent-key.json` (если в имени присланного файла есть `token` — `agent-token.json`, это запасной план Роберта):
`mkdir -p ~/.config/kontent-zavod && mv "<путь к файлу>" ~/.config/kontent-zavod/agent-key.json && chmod 600 ~/.config/kontent-zavod/agent-key.json`
(Windows: `New-Item -ItemType Directory -Force "$HOME\.config\kontent-zavod"; Move-Item "<путь>" "$HOME\.config\kontent-zavod\agent-key.json"`).
- Проверка: `ls -l ~/.config/kontent-zavod/` — есть `agent-key.json` (или `agent-token.json`). Скажи Кристине: «Ключ на месте — удалите сообщение с ключом у себя и у Роберта» (если передавали через Telegram или флешку — и файл на флешке).

**Шаг 5. Проверка доступа.** `cd ~/kontent-zavod && uv run crm/crm.py selftest --full`. Первый запуск сам скачает Python и библиотеки (1–2 минуты). Все строки должны быть «ОК», в том числе «папка проекта не в облачной синхронизации» и последняя — пробный прогон: он заводит пробного клиента и заказ в отдельной таблице «CRM проверка … — можно удалить» в папке «_проверка агента» и сверяет записанное с прочитанным; живой учёт не трогает. Затем `uv run crm/crm.py check` — «итог: ОК» (предупреждения допустимы, перескажи их). Любая «ОШИБКА» — таблица в Части 4.

**Шаг 6. Коннектор Google Drive.** Для учёта он не нужен. Если он подключён в настройках Claude — пользуйся им только для поиска и чтения; создавать, загружать и менять — только через `crm.py`.

**Шаг 7. Передача в рабочую папку (последний шаг этой сессии).** Сейчас ты работаешь в папке настройки; дальше с Кристиной работает новая сессия в папке `kontent-zavod`, и она тебя не помнит — поэтому всё, что ей нужно, лежит в этом же файле (он есть в корне репозитория). Сначала проверь сам: есть `~/kontent-zavod/.claude/settings.json`, `~/kontent-zavod/.claude/skills/клиент/SKILL.md` и `~/kontent-zavod/.claude/skills/заказ/SKILL.md`. Затем скажи Кристине дословно:
> Настройка почти готова. Откройте рабочую папку: в приложении Claude → Code → новая сессия → Local → Select folder → папка **kontent-zavod** в вашей домашней папке. Если Claude спросит, доверять ли папке, — ответьте «Доверять». Затем напишите в новой сессии: **«Закончи настройку по AGENT-KRISTINA.md, шаг 8»**. Эту сессию можно закрыть.

**Шаг 8 (новая сессия, папка `kontent-zavod`).** Тебя попросили закончить настройку. Шаги 0–7 уже сделаны предыдущей сессией — не повторяй их.
- `pwd` — путь кончается на `kontent-zavod`, и он не в «Рабочем столе», «Документах», OneDrive или iCloud. Иначе — попроси Кристину открыть правильную папку (шаг 7).
- `uv run crm/crm.py selftest` — все ОК.
- Назови Кристине три правила из CLAUDE.md своими словами: номера даёт скрипт; «выполнен» и ссылка на результат — только после полной оплаты; клиенту ничего не уходит без её «да». Не можешь — CLAUDE.md не прочитан: папка открыта не та.
- Ты не видишь меню приложения, поэтому спроси Кристину: «Наберите в поле сообщения знак / — есть ли в списке /клиент и /заказ?». Нет — таблица в части 4.
- Если Claude спросит разрешение на `uv run crm/crm.py …` — Кристина отвечает «Всегда разрешать для этого проекта».

**Шаг 9. Закладки.** Попроси Кристину открыть в браузере под её Google-аккаунтом ссылки на Таблицу CRM и общий диск из «Данных проекта» и добавить их в закладки.

**Готово, если.** Проверено тобой (шаги 1–8): три инструмента установлены; `gh auth status` — вход выполнен; есть `~/kontent-zavod`; `selftest --full` — все ОК; `check` — итог ОК; ты в папке `kontent-zavod` и знаешь правила. Подтвердила Кристина (ты спросил): в меню «/» есть `/клиент` и `/заказ`; таблица открылась по закладке. Сообщи ей это списком. Пробный запуск без записи (учёт настоящий, тестовые строки в нём не заводим — для этого был пробный прогон): `uv run crm/crm.py get Заказы --where "Статус!=выполнен"` — перескажи, что сейчас в работе.

## Часть 3. Правила работы (кратко)

Полные правила — в `CLAUDE.md` репозитория; при расхождении прав `CLAUDE.md`.
- Учёт и Диск — только через `uv run crm/crm.py …`. Номера даёт скрипт: клиент `К-0001`, заказ-товар `0012-1`. «ОШИБКА» скрипта значит «ничего не записано» — перескажи причину, не обходи.
- Перед записью покажи, что запишешь, и дождись «да». Файлы перед загрузкой — списком.
- Папка заказа: `ТЗ` (что прислал клиент, тз.md) → `Исходники` → `Работа` (черновики) → `На согласование` (превью с водяным знаком) → `Результат` (только после оплаты).
- Клиенту ничего не отправляешь сам: готовишь текст и ссылку, отправляет Кристина.
- Эскалация к Кристине: претензия, нестандартный заказ, скидка сверх правил, просьба клиента позвать человека.

Нельзя: удалять файлы и строки; менять первую строку таблицы и номера; класть файлы клиентов и ключ в репозиторий; давать ссылку на «Результат» до оплаты; писать о товаре то, чего нет в паспорте; пушить в `main`.

## Часть 4. Если что-то не так

| Сообщение | Что значит | Что делать |
|---|---|---|
| «нет ключа агента …» | ключ не на месте | Шаг 4 |
| `selftest`: «папка проекта … лежит в …» | проект склонирован в облачную папку | Шаг 3 заново в домашнюю папку; старую копию удалить после проверки |
| «Google ответил 403 …» | роботу не дали доступ к общему диску или таблице | Роберту: добавить робота на общий диск «Менеджером контента» |
| «Google ответил 401» или «invalid_grant» | ключ отозван | Роберту: выдать новый ключ, затем Шаг 4 |
| «заголовки не совпадают …» | кто-то изменил первую строку листа | вернуть как было (Таблица → Файл → История версий) |
| «ВНИМАНИЕ: правила не обновились» | на компьютере есть изменения, которых нет в GitHub | `git status`, показать Роберту, ничего не удалять |
| `selftest`: «доступ к папке по ссылке» — ОШИБКА | общий диск не даёт ссылки людям вне компании | Роберту: разрешить доступ людям вне компании в настройках общего диска; пока результат отдаём архивом в переписке |
| gh: 404 / Could not resolve | приглашение в GitHub не принято | письмо от GitHub → Accept |
| `selftest --full`: «Таблица хранит значения не так…» | Google хранит номера, даты или текст иначе, чем ждёт скрипт | в живой учёт ничего не заводить; показать ответ целиком Роберту |
| в меню «/» нет `/клиент` и `/заказ` | открыта не та папка или ей не доверились | новая сессия в `kontent-zavod`, на вопрос о доверии — «Доверять»; не помогло — Роберту |
| Claude «лимит исчерпан» | закончился лимит подписки | подождать сброса или перейти на Max |
| ошибка хука при запуске сессии (Windows) | автообновление правил написано для bash | в `.claude/settings.local.json` (личный файл, в GitHub не попадает) записать `{"disableAllHooks": true}`; Кристина в начале дня говорит «обнови правила» — агент делает `git pull --ff-only` |

## Часть 5. Если вкладки Code нет совсем

Временный ручной режим, пока не появится Pro/Max: агент в обычном чате готовит строку клиента или заказа текстом по столбцам `crm/schema.toml`, Кристина вставляет её в таблицу руками и пишет Роберту «проверь учёт» — его агент запускает `check` и `mkfolder`. Оплату Кристина в этом режиме не вписывает в «Заказы», а присылает Роберту «0012-1, 6 600, 28.11, Продамус» — его агент вносит её `pay`. Агент в чате обязан каждый раз говорить: «Я не записал это в таблицу — вставьте сами».
