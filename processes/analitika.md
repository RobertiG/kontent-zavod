# Регламент: аналитика ниши и конкурентов

Версия 1 от 27.10.2026. Источник: бизнес-план v18, раздел 6.2.

**Зачем:** понять, что показывают и пишут лидеры ниши и что болит у покупателей. Видео, слайды и SEO попадают в реальные запросы и выделяют товар среди конкурентов.

**Что получаем:** файл «аналитика.md» в «Исходниках» — 1–5 запросов покупателя с частотой, таблица до 10 конкурентов, выводы для слайдов, сценария и SEO. Программа заполняет блоки 9–10 паспорта.

**Кто делает:** программу разрабатывает Роберт. Кристина запускает её одной командой в Claude Code по паспорту товара и проверяет выводы.

**Как устроена программа:**

1.  По паспорту товара агент формирует запросы покупателя и проверяет их частоту в MPStats, оставляет 1–5 главных.

2.  Из MPStats берёт нишу и топ товаров по этим запросам.

3.  Отбирает до 10 конкурентов: тот же тип товара, близкая цена, высокий рейтинг и много отзывов.

4.  Собирает по каждому слайды, название, описание, характеристики, наличие видео и RICH-контента и отзывы с оценками 1–3.

5.  Claude анализирует: что делают все лидеры, что никто не показывает, боли покупателей с цитатами из отзывов, ключевые слова, рекомендации по порядку слайдов, 3–5 преимуществам и 3 болям для сценария.

6.  Сохраняет «аналитика.md» и заполняет блоки 9–10 паспорта.

- **Доступ:** платный аккаунт MPStats и токен API. **\[УТОЧНИТЬ\]** Тариф.

- **Правило:** материалы конкурентов используем только для анализа, контент студии всегда свой.

**Где учиться (Роберт):**

- [MPStats — MCP-интеграция для ИИ-агентов](https://mpstats.io/) — на русском. О чём: подключение MPStats к ИИ-агенту. Зачем: источник данных для аналитики и SEO.

- [mpstats-mcp — MCP-сервер поверх API MPStats (GitHub)](https://github.com/snsudak/mpstats-mcp) — на русском. О чём: готовый сервер для Claude — ниша, похожие товары, прогнозы. Зачем: основа программы.

- [MCP-сервер MP Manager](https://mpmgr.ru/features/mcp) — на русском. О чём: бесплатный MCP для данных Wildberries, Ozon и Яндекс Маркета. Зачем: **\[ПРЕДЛОЖЕНИЕ\]** запасной источник данных.
