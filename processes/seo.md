# Регламент: SEO карточки

Версия 1 от 27.10.2026. Источник: бизнес-план v18, раздел 6.5.

**Зачем:** товар индексируется только по ключевым запросам, без мусора. Нерелевантные запросы приводят покупателей, которые не покупают, и средняя конверсия карточки падает.

**Что получаем:** SEO-лист: название, описание, характеристики и хештеги для Ozon.

**Кто делает:** программу разрабатывает Роберт. Кристина запускает её одной командой в Claude Code и проверяет лист.

**Как устроена программа:**

1.  **Характеристики категории** — из API Wildberries и Ozon или MPStats: список заполняемых полей.

2.  **Ключевые запросы** — из MPStats: самые важные запросы по товару с частотой.

3.  **Примеры** — описания 10 конкурентов из аналитики ниши.

4.  **Заполнение:** ИИ-агент пишет название, описание, характеристики и хештеги Ozon по правилам ниже.

**Правила:**

- Только запросы, релевантные товару.

- Все факты — из паспорта товара.

- Длина полей — по ограничениям площадки.

- Каждое ключевое слово стоит один раз и в нужном поле.

**Проверка:** запросы соответствуют товару, характеристики заполнены по списку категории, факты совпадают с паспортом.
