# Промты: AI-видео

Версия 1 от 27.10.2026. Источник: бизнес-план v18, раздел 6.3.

## Промт 6 — сценарий (Claude)

***Что прикрепить к промту:** «паспорт.md» и «аналитика.md».*

```text
Напиши сценарий ролика [15 / 30 / 60] секунд для карточки товара на
маркетплейсе по шаблону [распаковка / проблема → решение / товар в деле].
Используй боли покупателя и преимущества из аналитики.
Разбей на сцены по 5 секунд. Для каждой сцены дай:
1) что в кадре, движение камеры и действие товара — на русском;
2) надпись на экране до 5 слов;
3) готовый промт кадра для Nano Banana Pro: товар с листа ракурсов,
реальный размер из паспорта и сравнение с привычным предметом,
опорный объект рядом, вертикальный кадр;
4) какие файлы прикрепить к кадру. Файлы в «Исходниках»: лист-ракурсов,
в-руке, фронт, 3-4-слева, 3-4-справа, бок, тыл, верх, деталь-…,
коробка-…, часть-…, раскладка-частей;
5) готовый промт анимации на английском для Kling: действие, движение
камеры, товар сохраняет форму и размер, 5 секунд.
В кадре только реальные функции из паспорта товара.
```

## Промт 7 — промт обложки для Kling (Claude)

***Что прикрепить к промту:** «паспорт.md» и главный слайд без надписей.*

```text
По паспорту товара напиши на английском промт для Kling: 6-секундная
анимация главного слайда, в которой товар выполняет своё ключевое
видимое действие — например, из увлажнителя идёт пар, из колонки
расходятся звуковые волны, соковыжималка наливает сок. Товар сохраняет
форму, цвет и логотип, камера статична, фон спокойный, начало и конец
совпадают для бесшовного повтора. Дай одну строку промта.
```

## Шаблоны сценариев

- **Распаковка:** коробка на столе → открытие → товар в кадре → 2–3 функции → товар в использовании → финальный кадр.

- **Проблема → решение:** ситуация с проблемой из отзывов → появление товара → результат.

- **Товар в деле:** 4–6 сцен использования в разных локациях.
