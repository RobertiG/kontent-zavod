# AGENTS.md — для Codex

Правила проекта — в `CLAUDE.md`: прочитай его целиком в начале каждой сессии, они действуют и для Codex. Здесь — только отличия.

- **Начало сессии.** Ветка `main` — выполни `git pull --ff-only` (так обновляются правила). Ошибка — скажи сотруднику: «Правила не обновились из GitHub — сообщите Роберту».
- **Навыки** — в `.agents/skills/`: это ссылка на `.claude/skills/`, её создают при настройке (`SETUP.md`, часть 4). Вход — навык `kontent`: сотрудник пишет обычными словами («сделай инфографику для HD2000») или `$kontent …`. Где в навыках написано `/kontent`, `/клиент`, `/заказ` — это навыки `kontent`, `клиент`, `заказ`.
- **Чем генерировать** — `processes/obshchie-pravila.md`, §4, колонка «Codex»: картинки — встроенное рисование (`image_gen`), Gemini — по слову «через Gemini» или после двух искажений товара подряд; видеообложка — Gemini; видео 15 / 30 / 60 сек — пока не делаем.
- **CRM** — MCP `uchet`, правила те же, что в `CLAUDE.md`. **MPStats** — MCP `mpstats`.
- «Браузер Claude», «плагин chrome-devtools» в навыках — в Codex это его браузер. Браузера нет — шаги с Gemini и страницами площадок не выполняй: скажи, что не получилось и почему.
- Навыков `pdf` и `docx`, как у Claude, нет — PDF и Word собирай локально (`pandoc`, `pdftoppm`, библиотеки Python) и проверяй рендером страниц.
